FleetOps Intelligence

Fleet operators need consistent data to understand vehicle utilisation, trip distances, and speed patterns. This project builds an Azure Databricks lakehouse that brings fleet records and tracking data together for trusted analytics.

  • Data ingestion: Connect Azure SQL Database to Azure Data Lake Storage Gen2.
  • Lakehouse pipeline: Organise data into Bronze, Silver, and Gold layers with PySpark and Delta Lake.
  • Governance and infrastructure: Use Unity Catalog and Terraform for controlled data access and reproducible cloud resources.

Azure Databricks · PySpark · ADLS Gen2 · Delta Lake · Unity Catalog · Terraform
