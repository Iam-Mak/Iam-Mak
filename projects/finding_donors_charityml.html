Finding Donors for CharityML

Supervised learning system for predicting potential donors and optimizing outreach efficiency.

Python Scikit-learn Pandas Supervised Learning Classification

Overview

Developed a machine learning system to identify individuals most likely to donate to CharityML, enabling more targeted outreach strategies while reducing unnecessary mailing costs.

The prediction task focused on classifying whether an individual earns more than $50,000 annually, a feature strongly correlated with donation likelihood.

Goal: Maximize donation effectiveness while minimizing outreach expenditure.

Dataset

  • Total records: 45,222
  • Income > $50K: 11,208 (~24.78%)
  • Income ≤ $50K: 34,014
  • Dataset sourced from the UCI Census Income dataset

Data Preprocessing

  • Handled skewed numerical features such as capital-gain and capital-loss
  • Normalized numerical variables for stable model training
  • Applied one-hot encoding to categorical features (103 total features)
  • Split dataset into training and testing sets (80/20)

Models Evaluated

  • Decision Tree Classifier
  • Gradient Boosting Classifier
  • Stochastic Gradient Descent Classifier (SGDC)

Model Selection

Gradient Boosting Classifier achieved the strongest performance based on accuracy and F-score evaluation metrics. Although training time increased compared to simpler models, the model generalized more effectively and reduced overfitting behaviour observed in Decision Trees.

Optimization

  • Applied grid search for hyperparameter tuning
  • Improved F-score through model optimisation
  • Balanced predictive performance and computational efficiency

Feature Importance & Selection

Analyzed feature importance to identify the most influential variables contributing to income prediction. A reduced feature set retained most predictive capability while improving model efficiency and interpretability.

  • Identified high-impact predictive features
  • Reduced dimensionality while maintaining strong performance
  • Improved training efficiency and interpretability

Results

The optimized model successfully identifies high-income individuals likely to donate, enabling more focused outreach campaigns and reducing unnecessary operational costs associated with large-scale mailing strategies.
