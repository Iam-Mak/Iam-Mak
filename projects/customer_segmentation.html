Vehicle Policy Lapse Prediction

Machine learning pipeline for predicting vehicle insurance policy lapse using behavioural and policy-level data.

Python Scikit-learn MLflow FastAPI Docker Azure

Overview

Developed a production-ready machine learning system using approximately 23,000 insurance policies to predict customer lapse risk. The pipeline generates probability scores to rank high-risk customers, supporting targeted retention strategies and operational decision-making.

The solution was deployed as a containerized FastAPI service on Azure for scalable real-time inference.

System Architecture

  • End-to-end workflow from preprocessing → training → inference API
  • Reusable training pipeline generating deployment-ready artifacts
  • FastAPI inference service for real-time predictions
  • Dockerized deployment on Azure Web App
  • Consistent inference using stored preprocessing and model artifacts

Model & Performance

Logistic Regression was used as the baseline model with class balancing strategies to address strong class imbalance (~13% lapse rate).

  • ROC-AUC: 0.60
  • Recall (Lapse): 0.96
  • Precision (Lapse): 0.13

The system was optimized for recall to maximize identification of high-risk customers.

Key Insights

  • Strong class imbalance made recall-focused optimisation critical
  • Premium-related variables showed high multicollinearity
  • Younger policyholders demonstrated higher lapse probability
  • Feature selection improved interpretability more than predictive performance

Business Impact

The system enables early identification of customers at high risk of policy lapse, supporting targeted retention campaigns and improving operational efficiency. Probability-based ranking helps prioritize interventions more effectively.

Deployment & Engineering

  • Dockerized using python:3.10-slim
  • FastAPI + Gunicorn inference service
  • Azure Web App deployment
  • Dependency management using requirements.txt
  • Non-root container execution for improved security
  • Optimized Docker builds using layer caching

Data & Features

  • ~23,000 policies with 19 input features
  • Removed highly correlated premium variables (>0.89 correlation)
  • Selected top 15 predictive features
  • Encoded categorical variables for model training
  • Handled skewed feature distributions

Future Improvements

  • Experimentation with XGBoost and LightGBM
  • Expanded MLflow experiment tracking workflows
  • Monitoring and drift detection pipelines
  • Automated retraining infrastructure
  • Model explainability integration
