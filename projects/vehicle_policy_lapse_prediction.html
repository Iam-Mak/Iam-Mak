Vehicle Policy Lapse Prediction

Predicting customer churn using behavioural and policy data

Python Scikit-learn MLflow FastAPI
Summary

Developed a production-ready ML system using ~23k insurance policies to predict lapse risk (~13% positive class). The system outputs probability scores to rank customers, enabling targeted retention strategies. Deployed as a containerized FastAPI service on Azure.

System Architecture
  • End-to-end pipeline: data → preprocessing → model → API
  • Training pipeline generates reusable artifacts
  • FastAPI service for real-time predictions
  • Dockerized and deployed on Azure Web App
  • Consistent inference using stored preprocessing and model artifacts
Model & Performance

Logistic Regression baseline with class balancing (~13% lapse).

Performance:

  • ROC-AUC: 0.60
  • Recall (Lapse): 0.96
  • Precision (Lapse): 0.13

Recall-focused approach to maximise detection of high-risk customers.

Key Insights
  • Strong class imbalance (~13%) makes recall critical
  • Premium-related variables were highly correlated and reduced
  • Younger policyholders show higher lapse rates
  • Feature selection improved interpretability more than performance
Business Impact

Enables early identification of high-risk customers, supporting targeted retention strategies and improving revenue stability. Helps insurers prioritise interventions efficiently.

Deployment & Engineering
  • Dockerized (python:3.10-slim)
  • FastAPI + Gunicorn API service
  • Deployed on Azure Web App
  • Dependency management via requirements.txt
  • Non-root container for improved security
  • Optimized builds using Docker layer caching
Data & Features
  • ~23,000 policies, 19 features
  • Removed highly correlated premium variables (>0.89)
  • Selected top 15 features
  • Encoded categorical variables
  • Handled skewed distributions
Future Improvements
  • Tree-based models (XGBoost, LightGBM)
  • Model tracking (MLflow)
  • Monitoring for data drift
  • Automated retraining pipeline
  • Add explainability layer
