Vehicle Policy Lapse Prediction

Predicting customer churn using behavioural and policy data

Python Scikit-learn MLflow FastAPI Azure Docker

Summary

Developed a production-ready ML system using ~23k insurance policies to predict lapse risk (~13% positive class). The system outputs probability scores to rank customers, enabling targeted retention strategies and operational decision-making workflows.

System Architecture

  • End-to-end ML workflow from ingestion → preprocessing → model → API
  • Reusable training pipeline generating deployment-ready artifacts
  • FastAPI inference service for real-time predictions
  • Dockerized deployment on Azure Web App
  • Consistent inference using persisted preprocessing artifacts

Model & Performance

Logistic Regression baseline trained using class balancing strategies to handle ~13% positive lapse distribution.

  • ROC-AUC: 0.60
  • Recall: 0.96
  • Precision: 0.13

Optimised for recall to maximise identification of high-risk customers.

Key Insights

  • Strong class imbalance made recall-focused optimisation critical
  • Premium-related variables showed strong multicollinearity
  • Younger policyholders demonstrated higher lapse rates
  • Feature selection improved interpretability more than raw performance

Deployment & Engineering

  • Dockerized using python:3.10-slim
  • FastAPI + Gunicorn inference service
  • Azure Web App deployment
  • Optimised container builds using layer caching
  • Non-root container execution for improved security

Future Improvements

  • XGBoost and LightGBM experimentation
  • MLflow experiment tracking
  • Monitoring and data drift detection
  • Automated retraining workflows
  • Model explainability integration
