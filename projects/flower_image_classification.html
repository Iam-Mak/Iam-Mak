Flower Image Classification

81.10% Accuracy • 102 Classes • MobileNetV2 • Lightweight Deep Learning Model

Transfer learning pipeline for efficient multi-class flower image classification using MobileNetV2.

Python PyTorch MobileNetV2 Transfer Learning Deep Learning

Overview

Developed a deep learning image classification system capable of recognizing 102 flower species using transfer learning with MobileNetV2. The model was trained to learn meaningful visual representations while maintaining computational efficiency.

The project focused on balancing prediction performance and lightweight deployment suitability for real-world applications.

Approach

Leveraged a pretrained MobileNetV2 backbone and replaced the final classification layer for custom multi-class prediction. Early layers were frozen during initial training to preserve learned feature representations while adapting the classifier to the flower dataset.

  • Transfer learning with MobileNetV2
  • Custom classifier head for 102-class prediction
  • Efficient training using pretrained features
  • Image preprocessing and normalization pipeline

Key Highlights

  • 102-class multi-category image classification
  • Lightweight architecture with ~3.5M parameters
  • Complete pipeline from preprocessing to inference
  • Efficient deep learning workflow using transfer learning
  • Balanced model performance and computational efficiency

Results

Achieved 81.10% test accuracy, demonstrating strong generalization capability on unseen flower images. The model performs reliably across most classes while remaining lightweight enough for efficient inference.

  • Accuracy: 81.10%
  • Classes: 102 flower categories
  • Architecture: MobileNetV2
  • Model Size: ~3.5M parameters

Key Insights

  • Transfer learning significantly improved training efficiency
  • Pretrained visual features generalized effectively across flower species
  • Lightweight architectures can achieve strong classification performance
  • Data augmentation improves robustness and generalization capability

Future Improvements

  • Fine-tuning deeper MobileNetV2 layers
  • Advanced augmentation strategies
  • Experimentation with EfficientNet architectures
  • Deployment as lightweight inference API
  • Mobile-friendly deployment optimisation
